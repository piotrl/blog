## piotrl.net

Personal blog, built with [Astro](https://astro.build/) and hosted on Netlify.

* Posts: `content/blog/<slug>/index.md` (slug = URL)
* `npm run dev` / `npm run build` / `npm run check`

### Analytics

Cookieless [Umami Cloud](https://umami.is/). Set `UMAMI_WEBSITE_ID` in the Netlify environment to turn it on; without it no script is rendered. The tracker only counts visits on the production hostname.
